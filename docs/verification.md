# 검증 및 수정 이력

기준일: 2026-10-03. 아래 결과는 웹 개발 및 GitHub 업로드 시 수행한 검증 기록이다. 이번 문서 정리에서 애플리케이션 테스트를 재실행한 결과는 아니다. 실제 Python/LLM 서비스와 운영 배포는 검증 범위 밖이다.

## 해결한 문제

- 로컬 비밀번호 파일이 게시 산출물에 포함되던 문제: 프로젝트의 빌드/게시 복사를 모두 Never로 지정하고 결과를 검증했다.
- 계정 화면 버튼 글자 대비, 거래 폼 라벨 연결, 좁은 화면 메뉴 배치를 보완했다.
- 마지막 페이지를 넘는 거래 조회: 마지막 유효 페이지로 보정하며 빈 목록은 1 / 1로 표시한다.
- Windows PowerShell 5.1 테스트 호환성: System.Net.Http 로드와 Korea Standard Time 대체 이름을 추가했다.
- 통계 DB 장애: 직접 오류와 EF가 감싼 연결 오류를 처리해 API/대시보드는503, 홈은 장애 안내를 제공한다. 알 수 없는 프로그래밍 오류를 일괄 숨기지 않는다.
- GitHub 업로드용 복사본에서 EF 도구 설정이 누락된 문제: .config/dotnet-tools.json 포함 후 통합 검증을 통과했다.

## 재현 방법

패키지·EF 도구 복원과 빌드는 [README](../README.md)를 따른다.

```powershell
dotnet run --project tests/StatisticsChecks
dotnet run --project tests/AnalysisChecks
powershell -NoProfile -File .\scripts\Test-DatabaseFoundation.ps1
```

통합 검증은 PostgreSQL 18의 별도 테스트 DB(55432)와 웹(5078)을 사용한다. 포트가 비어 있어야 하며 테스트 서버는 종료한다. 실제 개발 DB/서비스를 중단하거나 테스트 데이터로 변경하지 않는다. PostgreSQL 설치 경로는 스크립트의 PostgresBin 인수로 변경할 수 있다. Test-Accounts/Test-Transactions는 이 통합 테스트의 하위 스크립트다.

과거 단계별 중복 검토 문서는 이 문서로 통합했다. 원문과 초기 기획 기록은 로컬 artifacts/docs-before-cleanup-20261003에 보관하며 Git에 포함하지 않는다.
