# 검증 및 수정 이력

웹 개발·GitHub 업로드 검증은 2026-10-03 기준이며, 아래에 2026-10-10 Python 스텁 공동 연결 검증을 추가했다. 실제 LLM 모델과 운영 배포는 검증 범위 밖이다.

## 2026-10-10 Python 스텁 공동 연결

dev `c69bb6f`에서 C# 빌드(경고/오류 0), StatisticsChecks·AnalysisChecks, Python pytest 25개를 통과했다. 개발 DB에서 별도 테스트 계정과 샘플 거래 3건으로 다음을 확인했다.

- C# 웹(5077)·Python(5090) 실행 및 개발 DB 조회 정상.
- 실제 Python 월간 분석 엔드포인트 HTTP 200, C# 최초 리포트 생성 HTTP 201 및 mode=http.
- 같은 요청 반복 시 HTTP 200 및 동일 리포트 ID 재사용.
- 로그인 후 거래·대시보드·리포트 페이지 HTTP 200.
- 이번 달 지출 120,000원과 전월 같은 기간 100,000원으로 증가액 20,000원 문구 확인.

Python은 규칙 기반 스텁이며 이 결과로 실제 AI 모델의 사실성·성능을 보장하지 않는다. 이번 공동 검증은 정상 호출과 캐시 경로를 확인했으며 실제 Python 중단·시간 초과 경로를 새로 검증한 것은 아니다. 비밀번호와 서비스 키는 검증 문서에 기록하지 않는다. 재현 안내는 [로컬 통합 테스트](local-integration.md)를 따른다.

6단계 공동 실행 스크립트는 PowerShell 7 및 Windows PowerShell에서 별도 포트(5087·5091) 실행·DB 확인, Ctrl+C 후 두 포트 종료, 기존 포트 충돌 시 시작 거절을 확인했다. 기존 5077·5090 서비스는 유지했다. PowerShell 구문 검사와 `git diff --check`를 통과했다. `-SkipBuild`로 이미 검증된 빌드를 사용했으며 C# 소스 변경은 없다.

PR 전 재검토에서 한 서비스의 종료 실패가 다른 서비스 정리를 건너뛰지 않도록 종료 처리를 보완했다. Python 시작 실패를 유도하여 오류 안내, 두 서비스 포트 정리, 부모 환경변수 복원을 확인했다. 수정 후 Windows PowerShell 정상 실행·DB 확인·Ctrl+C 종료도 다시 검증했다.

## 해결한 문제

- 로컬 비밀번호 파일이 게시 산출물에 포함되던 문제: 프로젝트의 빌드/게시 복사를 모두 Never로 지정하고 결과를 검증했다.
- 계정 화면 버튼 글자 대비, 거래 폼 라벨 연결, 좁은 화면 메뉴 배치를 보완했다.
- 마지막 페이지를 넘는 거래 조회: 마지막 유효 페이지로 보정하며 빈 목록은 1 / 1로 표시한다.
- Windows PowerShell 5.1 테스트 호환성: System.Net.Http 로드와 Korea Standard Time 대체 이름을 추가했다.
- 통계 DB 장애: 직접 오류와 EF가 감싼 연결 오류를 처리해 API/대시보드는503, 홈은 장애 안내를 제공한다. 알 수 없는 프로그래밍 오류를 일괄 숨기지 않는다.
- GitHub 업로드용 복사본에서 EF 도구 설정이 누락된 문제: .config/dotnet-tools.json 포함 후 통합 검증을 통과했다.

## 재현 방법

패키지·EF 도구 복원과 빌드는 [README](../README.md)를 따른다.

```powershell
dotnet run --project tests/StatisticsChecks
dotnet run --project tests/AnalysisChecks
powershell -NoProfile -File .\scripts\Test-DatabaseFoundation.ps1
```

통합 검증은 PostgreSQL 18의 별도 테스트 DB(55432)와 웹(5078)을 사용한다. 포트가 비어 있어야 하며 테스트 서버는 종료한다. 실제 개발 DB/서비스를 중단하거나 테스트 데이터로 변경하지 않는다. PostgreSQL 설치 경로는 스크립트의 PostgresBin 인수로 변경할 수 있다. Test-Accounts/Test-Transactions는 이 통합 테스트의 하위 스크립트다.

과거 단계별 중복 검토 문서는 이 문서로 통합했다. 원문과 초기 기획 기록은 로컬 artifacts/docs-before-cleanup-20261003에 보관하며 Git에 포함하지 않는다.
